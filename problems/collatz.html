Problem 3 · Number theory

Collatz Conjecture

Pick any positive integer. If it's even, halve it. If it's odd, triple it and add 1. Does every starting number eventually reach 1?

Statement. For every positive integer n, repeatedly applying n → n/2 (if even) or n → 3n + 1 (if odd) eventually reaches 1.
First posed
Lothar Collatz, 1937
Verified up to
more than 2⁶⁸ ≈ 3 × 10²⁰
Best result
Almost all orbits get almost bounded (Tao, 2019)

Why it matters

On its own, the answer has few known consequences. It matters because it shows how badly current mathematics handles systems that mix multiplication with the digits of numbers in different bases. Here that means halving (base 2) and tripling (base 3).

It is also a model for a broad class of problems. Conway showed that natural generalizations of Collatz-type rules are undecidable: no algorithm can settle all of them. So any proof for the 3n + 1 rule must use something special about that rule.

Where things stand

Open. Every number up to more than 2⁶⁸ has been checked. A counterexample would have to either climb to infinity or fall into a cycle other than 4 → 2 → 1. Any such cycle is known to be astronomically long.

In 2019 Terence Tao proved the strongest result so far: for almost all starting numbers, the orbit eventually falls below any slowly growing bound you choose. "Almost all" is meant in the sense of logarithmic density. This is very close to what one expects, but it does not rule out a few exceptional numbers.

History of attempts

  • 1937Lothar Collatz poses the problem.
  • 1972Conway shows generalized Collatz problems can be undecidable.
  • 1976Terras proves almost every number eventually drops below its starting value.
  • 2003Krasikov and Lagarias: at least x0.84 of the numbers up to x reach 1.
  • 2019Tao: almost all Collatz orbits attain almost bounded values.
  • 2020sComputer verification is pushed beyond 2⁶⁸. Researchers also recast the problem as rewriting systems to be attacked with SAT solvers (Yolcu, Aaronson and Heule).

Ideas for solving it

  • Probabilistic heuristics. Each odd step followed by the halvings that come after it multiplies n by about 3/4 on average, so orbits should drift downward. Making this rigorous for every number, not just almost every number, is the core difficulty.
  • 2-adic dynamics. The map extends naturally to the 2-adic integers, where it is well understood (it is conjugate to a shift map). The challenge is to control what happens to ordinary integers inside that space.
  • Automated reasoning. Encode the problem as termination of a string-rewriting system and search for a termination proof by computer. This has proven weaker variants, though not the full problem.
  • Rule out cycles. Continued-fraction bounds on log₂3 already show that any other cycle must be enormous. Pushing these bounds further, alongside ruling out divergence, would cover both ways the conjecture could fail.

Try it yourself

Start from 27 and follow the rule by hand or in a spreadsheet. It takes 111 steps to reach 1 and climbs as high as 9,232 along the way. Then try 26 or 28 for contrast.
