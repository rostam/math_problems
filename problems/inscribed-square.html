Problem 8 · Geometry and combinatorics

Inscribed Square Problem (Toeplitz)

Does every closed loop drawn without crossing itself contain four points that form a square?

Statement. Every Jordan curve (a continuous closed loop in the plane that does not cross itself) contains four points that are the corners of a square.
First posed
Otto Toeplitz, 1911
Proven for
Convex, smooth and many other curves
Rectangles
Every Jordan curve inscribes one

Why it matters

It is one of the simplest open questions in geometry: a child can understand it. Yet it touches deep topology, because "continuous curve" includes wildly wiggly, fractal-like loops.

Recent progress used symplectic geometry, a field born from physics. So this elementary problem has become a showcase for powerful modern tools.

Where things stand

Open for general continuous curves. It is proven for convex curves, piecewise-analytic curves, smooth curves, locally monotone curves and several other large classes.

The difficulty is a limit problem. Approximate a wild curve by smooth ones, each of which contains a square. Those squares might shrink to a single point in the limit, and a point is not a square.

In 2020 Greene and Lobb proved that every smooth Jordan curve contains a rectangle of every aspect ratio, not just squares. The proof uses Lagrangian tori in four-dimensional space.

History of attempts

  • 1911Toeplitz announces the problem.
  • 1913Emch proves it for convex curves.
  • 1929Schnirelmann proves it for sufficiently smooth curves.
  • 1977Vaughan gives a beautiful proof, using a Möbius strip, that every Jordan curve contains a rectangle.
  • 1989Stromquist proves it for "locally monotone" curves, a large class.
  • 2017Tao proves it for curves formed by two Lipschitz graphs with constant less than 1.
  • 2020Greene and Lobb: smooth curves contain rectangles of every aspect ratio.

Ideas for solving it

  • Control the size of the square. Show that for any curve enclosing a region of a given area, some inscribed square has size bounded below. Then limits of approximations can't collapse.
  • Symplectic topology. Extend Greene and Lobb's Lagrangian methods from smooth curves to rougher ones.
  • Parity and counting. For generic smooth curves, the number of inscribed squares is odd. Find a version of that invariant that survives for continuous curves.

Try it yourself

Draw a random closed loop on paper, the stranger the better, and try to find a square with its four corners on the loop. Rotating a transparent square template helps. It seems always possible, which is why the problem is so tantalizing.
